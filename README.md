# Lucky 7 Slots

Three.js로 만든 카툰 3D 슬롯머신 게임입니다. 빌드 없이 `index.html` 하나로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. (Three.js는 unpkg CDN에서 불러오므로 인터넷 연결 필요)

## 조작

- 레버를 아래로 끌어 당기기, 또는 `Space` / `Enter`
- `↑` / `↓` : 베팅 조절
- `Esc` : 업그레이드 상점 닫기

## 진행

크레딧을 모아 퀘스트를 깨면 업그레이드 상점이 열립니다.

| 목표 | 이벤트 |
|------|--------|
| 200 → 20,000 | 퀘스트마다 새 업그레이드 공개 (기계 추가, 행운, 베팅 한도, 심볼 등) |
| 100,000 | 사신 등장 — 모든 슬롯 마지막 릴에 💀 죽음의 코인 (걸리면 당첨금 3배 손실) |
| 1,000,000 | 🪙 금괴 심볼 해금 — 🪙🪙🪙 = ×10,000 |
| 1,000,000,000 | 최종 미션: 사신과의 마지막 승부 |

크레딧을 모두 잃으면 사신과 동전 던지기로 부활 기회를 얻습니다. 엔딩을 볼 때마다 다음 판에 영구 보너스(당첨금·행운·최종 승부 승률)가 쌓입니다.
